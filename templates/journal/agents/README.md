# Agent journal

The work log of the agents that act in this repository: what was asked, what
was done and to which files, what was decided and why, what was left open —
written as the work happens, never rewritten afterwards. It is how any change
in the repository is traced back to the session that made it.

One file per agent per day, `YYYY-MM-DD-<agent>.md`, so a day's work sits
together and one agent's history is a glob away. The full convention is in
`AGENTS.md`.
