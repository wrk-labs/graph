# Inbox

Where things land before they have a home. A receipt, a paper, an idea, a
document someone sent — put it here and move on; deciding where it belongs
can wait. Anything, in any format.

Things pass through. Each item moves on to the directory that gives it
context, or into `archive/` if it is done, or is deleted if it was never
worth keeping. Something that has lived here a long time either deserves a
place of its own or does not matter.
